# Style reference

Voice devices per JP marker. Grow this with approved pairs as batches are reviewed.

| JP markers | English devices |
|---|---|
| ぜ / ねぇ / だろ / 〜じゃねぇか (Toji, rough boys) | clipped, casual: "ain't", "y'know", "c'mon", "damn", contractions everywhere |
| わよ / なさい / のよ / かしら (Minori, assertive girls) | brisk, teasing: "you know", "honestly!", "I wonder...", imperatives |
| やしょう / 坊 / 〜なすった / ですねぇ (old-style retainer speech) | courtly-folksy: "young master", "shall we be off", "if you'd permit me" |
| じゃ / のう / わし / 妾 / 其方 (elders, ancient beings) | archaic: "thou" avoided; "I daresay", "child", "indeed", "'tis" sparingly; 妾 -> regal "I" with formal tone |
| です / ます (polite strangers, staff) | plain polite English, no slang |
| 某 / 拙者 / 〜でござる | samurai-stiff: "this one", "I shall", formal |
| ……。 | `...` (alone: `...`) |
| ―――(trailing) | `--` |

## Example pairs
| JP | EN |
|---|---|
| 水場は動き辛いぜ、\n気をつけろよ？ (Toji) | Water's a pain to move through. Watch your step, yeah? |
| 水で動きが鈍るわ。\n注意しときなさい。 (Minori) | The water slows you down. Be careful, okay? |
| おっとあれは……？\n坊、調べておいちゃどうです？ | Oh? What's that...? Young master, why not take a look? |
| 夕暮れが街を包む――― (man in black coat) | Dusk swallows the city-- |
